`0-alias` crea un alias de nombre `ls` para el valor `rm -f *`.
`1-hello_you` imprime `hola user` donde `user` es el nombre del usuario actual.
`2-path` agrega `/action` a la `PATH` como el ultimo directorio que la shell revisa al buscar un progama .
`3-paths` cuenta el numero de directorios en el `PATH`.
`4-global_variables` crea una lista de las variables de entorno.
